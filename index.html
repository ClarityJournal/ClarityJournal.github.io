Was ist neu
Die Änderungen stehen bei jeder neuen Version hier.
Windows

Einrichten

  1. Clarity-Setup.exe öffnen und installieren. ATAS vorher schließen.
  2. Clarity starten, deinen Gerätecode an mich schicken.
  3. Lizenz eintragen, dann unter Einstellungen → Plattformen deine Plattform verbinden.
Mac

Einrichten

  1. Clarity-mac.zip öffnen, Clarity in „Programme“ ziehen.
  2. Beim ersten Start: Rechtsklick → Öffnen.
  3. Gerätecode schicken, Lizenz eintragen, MT5 verbinden.
Plattformen

ATAS · NinjaTrader · MT5

  1. ATAS: Indikator „ClarityJournal“ auf einen Chart je Konto legen.
  2. NinjaTrader: nach der Installation im NinjaScript Editor einmal F5 drücken.
  3. MT5: Experte „Clarity“ auf einen Chart ziehen, „Algo-Handel“ einschalten.
